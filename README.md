## 🎯 What I'm Building

### ♟️ TEORIAT Chess Engine
A personalized chess AI that learns directly from my complete Chess.com history and imitates my real playing style instead of stock engine moves. [web:2]  
It uses a sequential PyTorch model where each move is encoded as a compact tuple `(color, move id, TEORIAT flag)` and predicts the next move from a learned move vocabulary. [web:2]
